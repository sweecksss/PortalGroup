# Portal Group

## Запуск у Windows

Установіть Python 3.10 або новіший і виконайте з кореня проєкту:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\runserver.ps1
```

Скрипт знаходить встановлений Python, створює ізольоване середовище `.venv`, встановлює залежності, застосовує міграції та запускає сервер. Після запуску відкрийте `http://127.0.0.1:8000/` — коренева адреса веде на сторінку оголошень.
